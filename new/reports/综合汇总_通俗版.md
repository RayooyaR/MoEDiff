## 先看结论（最重要的 6 句话）

1. **三台服务器 320 个任务全部跑完，没有一个失败**（A 53 个 / 4.8 小时；B 157 个，其中 153 个运行、4 个因"与默认配置相同，无需重复复核"而按规则跳过 / 6.9 小时；C 110 个 / 6.3 小时）。
2. **"扩散模型 + 时频专家"在没见过的干扰上明显比 CNN 强，这一点是稳的**；但在训练里见过的干扰上，CNN 和 U-Net 更好。
3. **计划里的两个创新点，目前都没有得到数据支持**：
   - 创新点 I（跨干扰迁移的物理知识 MoE：共享专家、属性监督、双因素路由等）：和"只用时频专家"相比，**没有稳定的额外收益**。
   - 创新点 II（CNN 初始估计 + 残差扩散 + 自适应修正）：在见过的类型上和 CNN 差不多，在没见过的类型上反而被它继承了 CNN 的弱点，**比直接用扩散差很多**。
4. **有三个结论是站得住的**：物理域专家比同样大小的普通 CNN 分支更能泛化；真正的稀疏门控（Top-K）没有帮助；U-Net 做主干在"见过的干扰"上大幅领先。
5. **最大的风险是"随机种子运气"**：同一个配置换一个随机种子，没见过类型上的误码率能差 0.01～0.03，比很多"改进"的幅度还大。计划里大部分对比只有 1 个种子，**不能当结论**。
6. **有一个对论文很关键的问题**：自动选择只看"见过类型的验证误码率"，于是选了 U-Net。而 U-Net 恰恰在整组没见过的干扰上更差。选择标准需要改（见最后一节）。

## 0. 怎么读这些数字（几个必须知道的概念）

| 词 | 通俗解释 |
|---|---|
| **BER（误码率）** | 恢复出的信号解调后，错了多少比例的比特。越低越好。不做任何处理直接解调的 BER 叫"输入 BER"（平均约 0.25）。 |
| **见过 / 没见过（未见）类型** | 训练时包含的干扰类型叫"见过"；训练时完全没出现、测试才出现的叫"未见"。**本文的"未见"有两种口径**：①"zs2 设置"——训练只含单音/多音/窄带/宽带/脉冲，测试的"未见"是整个调频家族（LFM、NFM、RFM 三类一起没见过）；②"逐类留出（LOTO）"——只把某一个类型拿走，其余 7 类都训练。 |
| **ΔBER（改善量）** | 输入 BER 减去恢复后 BER，越大越好。 |
| **负增益比例** | 恢复之后反而比不处理更差的样本比例。比如 35% 表示三分之一的样本被"修坏"了。 |
| **平均 8 次采样** | 扩散模型每次生成的结果有随机性，所以对同一条信号独立生成 8 次再取平均。这样误码率会明显降低，但每条信号要算 8 倍。本文扩散模型的数字全是这个口径。 |
| **种子（seed）** | 训练时的随机数起点。同一个配置换一个种子，结果会有波动。 |

### 这批结果有多可信？

- **机器差异很小**：三台机器各跑了同一个"锚点"配置（TF-only，种子 42）：没见过类型的 BER 分别是 0.0787 / 0.0817 / 0.0801，见过类型 0.1025 / 0.1033 / 0.1029；CNN 三台**完全一样**（0.0873 / 0.1703）。所以**不同机器之间的结果可以比较**，差别不超过 0.003。
- **种子波动很大**（这才是主要不确定性）。同一个配置跑 3 个种子，没见过类型的 BER：

| 配置 | 种子 42 / 43 / 44 | 最大差距 |
|---|---|---|
| 只用时频专家（TF-only） | 0.081 / 0.112 / 0.104 | **0.031** |
| 四个物理专家 | 0.099 / 0.091 / 0.106 | 0.015 |
| 4 个普通 CNN 分支（对照） | 0.115 / 0.122 / 0.133 | 0.018 |
| 四专家 + 静态均匀融合 | 0.116 / 0.117 / 0.120 | 0.004 |

  **经验规则：差距小于 0.02 的"提升"，除非有 3 个以上种子，否则不要相信。** 报告里的"置信区间"只反映测试样本的随机性，不包含这个种子波动，所以单种子对比会显得"很显著"，其实不可靠。

## 1. 先给全景：最核心的几张表

### 1.1 整组调频干扰没见过（zs2 设置）——谁最好

| 方法 | 见过类型 BER | **未见类型 BER** | 备注 |
|---|---|---|---|
| 不处理（输入） | 0.225 | 0.291 | |
| CNN | 0.087 | 0.170 | 见过的好，没见过的差 |
| 扩散，无专家（DiT） | 0.134 | 0.104 | |
| 扩散 + 时频专家（DiT） | 0.119（3 种子） | **0.099（3 种子）** | 未见类型最好那一档 |
| 扩散 + 四个物理专家 | 0.122（3 种子） | 0.099（3 种子） | 和只用时频专家没区别 |
| 扩散 + U-Net 主干 + 时频 | **0.073** | 0.109 | 见过的最好，没见过的变差 |
| 残差扩散（CNN 打底） | 0.091 | 0.144 | 像 CNN，没见过类型不好 |

**一句话**：没见过的干扰上，"DiT 扩散 + 时频专家"最好；见过的干扰上，"U-Net 扩散"最好；CNN 和残差扩散夹在中间偏"见过类型强、没见过类型弱"。

### 1.2 只把某一个干扰类型拿走（逐类留出，5 个类型，被拿走类型上的 BER）

| 被留出的类型（不处理时 BER） | CNN | 扩散无专家 | 扩散+时频 | 静态四专家 | 四专家(旧路由) | 双因素+属性 | 最好的是 |
|---|---|---|---|---|---|---|---|
| 线性调频 LFM（0.287） | **0.037** | 0.083 | 0.069 | 0.062 | 0.078 | 0.077 | CNN |
| 随机调频 RFM（0.291） | **0.061** | 0.080 | 0.079 | 0.070 | 0.077 | 0.080 | CNN |
| 多音 MT（0.270） | 0.183 | 0.158 | 0.150 | **0.138** | 0.143 | 0.167 | 静态四专家 |
| 脉冲 PL（0.051） | 0.059 | 0.070 | **0.040** | 0.075 | 0.060 | 0.047 | 扩散+时频 |
| 宽带 WB（0.248） | **0.257** | 0.277 | 0.284 | 0.289 | 0.274 | 0.281 | 无人有效 |

读法与解释：
- **留出 LFM、RFM 时 CNN 最好**：训练里还有相近的调频类型（比如拿走 LFM，NFM 和 RFM 还在），CNN 可以"举一反三"。整组调频家族一起拿走（1.1 节）时，CNN 就垮了（0.170）。这个解释是推断，没有单独验证。
- **留出 MT（多音）、PL（脉冲）时扩散模型更好**：这两类和其他类型"性质不同"，CNN 迁移不过去。
- **留出 PL**：这类干扰很少碰到信号（不处理时 BER 只有 0.051），**CNN 和大多数模型反而把它修坏了**（负增益 33%～44%），只有"扩散+时频"（0.040）和"双因素+属性"（0.047）比不处理好。
- **留出 WB（宽带）：所有方法都比不处理还差**（0.257～0.289 对 0.248）。宽带干扰覆盖整个信号频带，目前没有任何方法能处理，这是个真实的短板。
- 带 3 个种子的行种子间差距也有 ±0.01 左右，单种子的行（无专家、静态四专家、双因素、共享专家）只能参考。
- **B 机用自动选出的 U-Net 主干复核了 3 个类型**（各 1 个种子；留出类型 BER）：留出 LFM——U-Net+时频 **0.0215**、胜出 MoE（共享+四专家）0.0245、CNN 0.0358；留出 MT——胜出 MoE **0.1107**、U-Net+时频 0.1441、CNN 0.1837；留出 PL——U-Net+时频 **0.0407**、CNN 0.0580、胜出 MoE 0.0626。**U-Net 扩散在单个类型被留出时是目前最好的**（LFM 比 DiT 版 0.069 和 CNN 0.037 都好），只有"整组调频一起没见过"时才不如 DiT。

## 2. 逐项回答 plan.md 的 16 个实验

> 图例：✅ 数据支持；❌ 数据不支持；⚠️ 说不清（种子噪声大或证据不足）。

### 第一部分：MoE（专家混合）能不能学到可迁移的物理知识

| 实验 | 做了什么 | 发现（没见过类型 BER，单位 BER） | 通俗结论 |
|---|---|---|---|
| **E1 单个专家有没有用** | 频域/时频/时域/多尺度专家分别单独用，和四专家、静态均匀融合、4 个普通 CNN 分支比 | 四专家 0.0985；只时频 0.0989；4 个普通 CNN 分支 **0.1234**；静态均匀融合 **0.1176**；单专家（各 1 种子）：频域 0.133、时域 0.098、多尺度 0.089 | ✅ **物理专家 + 路由比同样大小的普通 CNN 分支好约 0.025，比静态均匀融合好约 0.019**（这两个差距大于种子波动）。⚠️ 但**四个专家不比只用时频专家更好**。 |
| **E2 共享专家** | 在四专家上加一个始终启用的通用分支 | 加共享 0.0889（1 种子）、共享+时频 0.1110、两个普通分支 0.1160，对照四专家 0.0985（3 种子） | ⚠️ 差距在种子噪声内，**没有证据说共享专家有用**。 |
| **E3 物理属性辅助监督** | 让专家额外预测干扰的物理量（带宽、调频速率、占空比等）；联合训练 / 先预训练再冻结 / 先预训练再微调 | 联合 0.1044、冻结 0.0973、微调 0.0863、时频+属性 0.0821（均 1 种子），对照 0.0985 | ⚠️ 看起来"预训练后微调"和"时频+属性"略好，但差距不超过种子噪声。**探针检验**（冻结专家特征去预测没见类型的物理量）：时域、多尺度两组特征比随机专家略好，频域、时频两组没有，没有稳定迹象表明学到了可迁移的知识。 |
| **E4 形态—强度双因素路由** | 路由器同时看"干扰长什么样"和"干扰多强（估计信干比）" | **路由确实变了**：门控被"干扰类型"解释的比例从旧路由的 3% 升到 38%；信干比估计平均只差 1.7 dB。但误码率：双因素 0.1159、旧路由 0.0985、去掉交互项 0.0967、只看强度 0.0933 | ✅ 路由确实更像"分工"了；❌ **但没有带来更好的泛化**（双因素还略差）。即使把真实信干比喂给路由（上界对照）也只有 0.0962，说明瓶颈不在路由。 |
| **E5 融合机制** | 静态均匀 / 加权求和成一个 token / 软权重 / Top-K 真屏蔽 | 静态均匀 0.1163；加权求和 0.1034；软权重（旧路由）0.0985；Top-K 真屏蔽 0.1144 | ✅ **静态均匀最差**，说明"有路由"比"没路由"好；❌ **真正的稀疏（Top-K 屏蔽）没有带来好处**。 |
| **E6 逐类留出** | 5 个类型轮流拿走（见 1.2 表） | 见 1.2 | ✅ 迁移能力取决于"被拿走的类型有没有相近的兄弟类型"；❌ 改进版 MoE（双因素+属性）和"只用时频专家"相比：5 个类型里 4 个更差（LFM +0.008、RFM +0.001、MT +0.017、PL +0.007），只有 WB 上略好 0.003（而 WB 所有方法都失败，没有意义）。 |

### 第二部分：扩散主干与"保真恢复"

| 实验 | 做了什么 | 发现 | 通俗结论 |
|---|---|---|---|
| **E7 去噪主干** | DiT / U-Net（两种大小）/ DiffWave 比较 | **U-Net**：见过类型 BER **0.073**（DiT 0.103），没见过 0.107（DiT 0.081）；DiffWave 最差（0.136～0.114）。U-Net(64) 有 11.7M 参数，采样比 DiT 慢约 2～3 倍（测量时机器有并发，仅供参考） | ✅ **U-Net 是"见过类型"的最强主干**，大幅领先；❌ 但在整组没见过的干扰上不如 DiT。**这是选哪个主干的核心取舍。** |
| **E8 局部时频 token** | 把时频特征切成 16 / 32 段保留位置 | 全局 0.0809；16 段 0.0896；32 段 0.0908 | ❌ 保留位置信息**没有帮助**。 |
| **E9 条件注入方式** | 交叉注意力 / FiLM / AdaLN | 0.0809 / 0.0888 / 0.0889 | ⚠️ 交叉注意力最好或持平，没有理由换。 |
| **E13 采样步数与次数**（A 机） | 10/25/50/100 步 × 单次/平均 8 次 | 单次：10 步 0.1457 → 25 步 0.1364 → 100 步 0.1337；平均 8 次：0.1019 → 0.0965 → 0.0953 | ✅ **25 步够用**（再增加几乎没用）；✅ **平均 8 次比增加步数有效得多**（0.136 → 0.097），但每条信号的计算量是 8 倍（25 步时约 41 毫秒/条）。 |

### 第三部分：创新点 II——"CNN 打底 + 扩散只修残差 + 自适应修正"

| 实验 | 发现 | 通俗结论 |
|---|---|---|
| **E10 残差扩散** | CNN 基础估计：见过 0.0887 / 未见 0.1604。普通残差 CNN（不用扩散）：0.0896 / 0.1609。**残差扩散**（3 种子）：0.0907 / **0.1439**。直接扩散（时频）：0.1189 / **0.0989** | 残差扩散**确实比 CNN 本身在没见过类型上好 0.017**（普通残差 CNN 做不到，说明扩散本身有用），**但仍远不如直接扩散的 0.099**；在见过类型上则和 CNN 一样（甚至差 0.002）。结论：❌ 它继承了 CNN 的"见过类型强、没见过类型弱"。 |
| **E11 自适应修正（门控）** | 在验证集上，不用残差（λ=0）BER 0.0900，全用残差（λ=1）0.1138，学出来的门控 0.0901——**门控学成了"把扩散残差基本关掉"**。测试时没见类型上 0.1603（反而比全用残差 0.1439 差） | ❌ 门控在"见过类型的验证集"上学习，那里残差确实有害，于是把它关掉；但在没见过的类型上残差其实是有用的。**这是选择标准问题（见最后一节）。** 值得肯定的一点：**强信号（信干比 +10 dB）时"把好符号修坏"的比例**，直接扩散 35%，CNN 和残差类约 21%～23%——"弱干扰保真"的问题确实被缓解了，但缓解来自 CNN 打底，不是门控。 |
| **E12 物理一致性引导**（A 机，可选） | 用一个独立训练的"干扰估计器"，让生成的信号与"观测 − 估计的干扰"保持一致。在验证集上权重越大越好（0.1505 → 0.0973，最大权重 3 在网格边缘）。测试集上单次采样 0.1385 → 0.1120 | ✅ **有明显效果**（单次采样降低约 0.027，是这次唯一看起来明显有效的"新增件"），但仍不如"平均 8 次"（0.0983）；还没试"引导 + 平均 8 次"和更大权重，也没算额外耗时。 |

### 第四部分：小样本与两项创新的联合

| 实验 | 发现 | 通俗结论 |
|---|---|---|
| **E14 物理增强**（C 机，10% 数据） | 6 种增强逐个试。不增强 3 种子：见过 0.1205、未见 0.1013。**加噪（awgn）3 种子：0.1115 / 0.0972**；组合 3 种子：0.1111 / 0.1004；旋转/时移/IQ 失配/重新混合（单种子）反而略差或持平 | ⚠️ **所有增强的改善都小于不增强自己的种子波动（±0.013），不能说有效**。最像有用的是"给输入加噪声"，但差距也在噪声里。重新混合干扰（remix）单种子没有改善。再次印证：之前"通用增强对小样本没用"的结论。 |
| **E15 训练数据比例** | 见下表 | ✅ **扩散模型的"没见过类型"成绩几乎不随数据量变化，10% 数据就够**；CNN 的"见过类型"成绩随数据增加而明显进步，但"没见过类型"一直没起色。 |
| **E16 两项创新的联合** | 见下表 | ❌ **两项创新单独都不如基线，联合后也不比基线好。** |

**E15（没见过类型 BER / 见过类型 BER）**

| 训练数据 | CNN | 扩散无专家 | 扩散 + 时频（DiT） | U-Net 扩散（本计划胜出配置，含新 MoE） |
|---|---|---|---|---|
| 10% | 0.186 / 0.141 | 0.098 / 0.122 | **0.100** / 0.120 | 0.142 / **0.094** |
| 30% | 0.183 / 0.107 | 0.089 / 0.118 | **0.083** / 0.106 | 0.125 / **0.079** |
| 100% | 0.176 / 0.087 | 0.099 / 0.133 | **0.092** / 0.117 | 0.130 / **0.072** |

**E16（U-Net 骨架内部，各 2 个种子；没见过 BER / 见过 BER）**

| 编号 | 配置 | 10% 数据 | 100% 数据 |
|---|---|---|---|
| J0 | 只用时频条件，普通扩散（基线） | 0.125 / 0.090 | **0.108 / 0.072** |
| J1 | 新 MoE（共享+四专家），普通扩散 | 0.142 / 0.094 | 0.130 / 0.072 |
| J2 | 只用时频，自适应残差扩散 | 0.128 / 0.092 | 0.153 / 0.083 |
| J3 | 新 MoE + 自适应残差扩散（两项都用） | 0.136 / 0.096 | 0.153 / 0.082 |
| J4 | 静态多分支 + 残差扩散（参数量对照） | 0.128 / 0.091 | 0.151 / 0.081 |
| J5 | 新 MoE + 直接监督的 CNN（不用扩散） | 0.183 / 0.135 | 0.175 / 0.082 |

- 加了"新 MoE"（J1）或"残差扩散"（J2）都**比基线 J0 差**；两个都加（J3）也不更好。
- J5 对比 J1：同样的 MoE，用扩散比用 CNN 好很多（没见过类型 0.130 vs 0.175），说明**扩散本身值得保留**。
- 报告里算出的"交互量 δ"全为正（+0.001～+0.012），按公式字面意思是"协同"，**但这里要小心**：因为单独加 MoE、单独加残差都让结果变差，δ 为正只说明"两个坏处叠加起来没有简单相加那么糟"，**不代表有协同收益**。
- 注意：E15/E16 里 B 机的行用的是自动选出来的 U-Net 主干，所以"没见过类型"的数字（0.13～0.15）不如 C 机 DiT 的行（0.09～0.10）。这不是 MoE 或残差的责任，是主干选择的结果（见最后一节）。

### 第五部分：P0 审计

| 检查项 | 结果 |
|---|---|
| 各数据集的训练/验证/测试 clean_id 互不重叠 | ✅ 全部通过 |
| 数据定义（混合 = 干净 + 干扰 + 噪声；信干比/信噪比与保存值一致；干净信号解调零误码） | ✅ 全部通过，误差为零 |
| 重算 BER 与已保存结果一致 | ✅ 0.0983 = 0.0983 |
| Top-K "乘零"是否等于真屏蔽 | ❌ **不等价**：只把权重乘 0，被屏蔽专家仍通过偏置影响输出（实测输出差约 0.05～0.08）。所以 E5 里的"真屏蔽"才是真的稀疏。 |
| 旧的"无 MoE"基线是否真的无条件 | ❌ **不是**：旧基线传入的是全零的假 token，仍会产生非零输出（实测差约 0.07）。本批新结果里的"无专家"配置都用了真正的无条件分支。 |

## 3. 对两个创新点的最终判断

### 创新点 I：跨干扰泛化的物理知识 MoE
- **站得住的部分**：物理域专家 + 路由 > 同样大小的普通 CNN 分支（没见过类型好约 0.025）> 静态均匀融合（好约 0.019）。也就是说，"领域知识"确实有价值，而且"有路由"比"没路由"好。
- **站不住的部分**：共享专家、属性辅助监督、双因素路由、Top-K 真稀疏、局部时频 token——**没有一个有稳定的额外收益**；四专家并不比只用时频专家好。
- **建议的论文表述**：不要写"提出了共享专家/属性监督/双因素路由"这些贡献；可以写"**时频专家条件 + 扩散**"，并用 E1 的对照（物理专家 vs 普通 CNN 分支 vs 静态融合）支持"物理域表征有价值"。

### 创新点 II：干扰自适应的保真残差扩散
- **站得住的部分**：用 CNN 打底、扩散修残差，确实**缓解了强信号下"把好符号修坏"**（35% → 约 21%）；扩散部分比普通残差 CNN 有用。
- **站不住的部分**：整体误码率**没有超过**直接扩散；没见过类型上继承了 CNN 的弱点；自适应门控被训练成"关掉扩散"，对没见过类型有害。
- **建议**：先不要把它作为主要贡献；如果要做，需要先解决"门控在什么数据上学"的问题（见下一节）。

### 目前最强的、可以写的结论
1. **扩散 + 时频条件，对"整组没见过的干扰"的泛化明显好于 CNN**（0.099 vs 0.170），且 **10% 训练数据就够**。
2. 对"见过的干扰"，U-Net 扩散最强（0.072～0.094），已超过 CNN（0.087～0.141）。
3. 物理域表征（专家 + 路由）比普通 CNN 分支更能泛化。
4. 平均 8 次采样、25 步，是成本与效果的合理折中；物理一致性引导（E12）是一个有前景的额外手段。

## 4. 存在的问题与下一步建议

### 4.1 必须承认的局限
1. **种子数不够**：E2～E5、E7～E9 大多只有 1 个种子，E15/E16 只有 2 个。这些里面看到的"差 0.01～0.02"不能当结论。
2. **自动选择的标准有偏**：选择只看"见过类型的验证误码率"，所以选了 U-Net（见过类型最强）；但"整组没见过"的场景下 DiT 更好。**这个选择直接影响了 E15 与 E16 的所有 B 机行**，也让残差门控学歪了。
3. **逐类留出里有 3 个模型只有 1 个种子**（无专家、静态四专家、双因素、共享专家），不能做细致比较。
4. **宽带干扰（WB）整体失败**，不属于某个方法的问题，是整个体系的盲区。
5. **E12 的最优权重在网格边缘**，没有找到拐点；也没有算"引导 + 平均 8 次"的组合和额外耗时。
6. 三台机器的代码哈希不同（C 机修过一个与训练无关的并行启动脚本），按 C 机的说明不影响训练和评估结果；锚点任务的一致性也支持这一点。

### 4.2 我建议的下一步（按性价比排序）
1. **把选择标准改成能反映"没见过"的**：比如在训练类型里再留出一个类型当"伪未见"验证集（不碰真正的测试类型），再重新选主干和 MoE。这是最可能改变结论的一步。
2. **关键对比补种子到 5 个**：只补这几组就够——"DiT+时频 vs U-Net+时频"、"四专家 vs 只时频"、"四专家 vs 普通 CNN 分支"、"残差扩散 vs 直接扩散"。每组大约 3～4 小时（一台机器）。
3. **试"两头兼顾"**：U-Net 擅长见过类型，DiT 擅长没见过类型，可以试把两者结合（比如按路由选、或取平均），这可能是比 MoE 细节更值得做的创新。
4. **宽带干扰专项**：单独研究为什么所有方法都失败，是否需要专门的专家或不同的建模方式。
5. **E12 继续**：加大引导权重，试引导 + 平均 8 次，测耗时。
6. **门控改成在"带伪未见类型的验证集"上训练**，再检验残差扩散是否能同时拿到"见过强 + 没见过也强"。
