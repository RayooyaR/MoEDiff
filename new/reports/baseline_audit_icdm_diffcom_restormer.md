# 基线代码核对与设计：ICDM / DiffCom / Restormer

> 核对对象：本项目 `new/moe_diffic/models/baseline_new.py`（`ICDMDual1DBaseline`、`DiffCom1DBaseline`，即实际使用的版本）。
> 参照：官方 ICDM（github.com/Wireless3C-SJTU/ICDM）、官方 DiffCom（github.com/wsxtyrdd/diffcom，IEEE JSAC 2025）、官方 Restormer（github.com/swz30/Restormer）。官方代码已下载到 `/root/autodl-tmp/ref_repos/`，逐文件比对。
> 旧文件 `models/baseline/semantic_diffusion_baselines.py` 里的同名类有硬伤（训练时把干净信号当条件输入、依赖不存在的文件、DPS 引导取 batch 平均几乎无效），**实际没有被使用，也不应再引用**。

## 1. ICDM —— 结论：合理的"简化迁移"，不是逐项复现；可信度：中

**官方做法**：两个无条件扩散先验（信号 s、干扰 n，各自在自己的数据上训练，1000 步 VP）；采样时同时维护信号和干扰两条轨迹（UniPC 三阶求解器，40 步，确定性），把观测约束 y ≈ A·x + A'·n 当软引导加到两条轨迹上（用到已知的 SNR 和 SINR）。

**本项目**：同样两个无条件 ε-预测先验（信号先验用干净信号训练，干扰先验用"干扰+噪声"本身训练，训练时互不相见）；采样时只保留一条轨迹，把 y = x + b 当硬约束，b̃ = y − x_t/√ᾱ，两个分数组合为 ε = ε_s − γ·ε_b，b 先验按噪声水平对齐时间步。

| 项 | 判断 |
|---|---|
| 两个无条件先验、干扰先验学的是干扰而非干净信号 | 一致 |
| 测试时不使用干扰类型标签、SIR 标签 | 一致（且比官方用的信息更少，官方用已知 SNR/SINR） |
| 单轨迹 + 硬约束代替双轨迹 + 软引导 | 合理的 1D 适配，但是简化（噪声并入干扰，两条轨迹噪声反相关，高噪声段是启发式组合） |
| 求解器 | 偏差：一阶 DDIM 25 步，官方 UniPC 三阶 40 步 |
| 干扰先验不分类型、用单一全局尺度归一化 | 方法限制（官方每种干扰一个先验，并用 SINR 缩放） |
| γ 在验证集上调参，且限定为训练见过的类型 | 无测试集泄漏 |

**可能让 ICDM 偏弱的点**（影响从大到小，均**未量化**）：求解器阶数/步数；γ 对结果很敏感（验证集 BER：γ=0.25→0.32，0.75→0.153，2.0→0.19）；训练时挑最优 epoch 用 γ=1.0 而调参最优是 0.75；`exp_`、`ef_` 前缀的 run 不在 `tune_and_eval.py` 的 SEEN 表里，验证集可能混入未见类型（数值上看没有影响，但应补上）。

**建议补做（按价值排序）**：
1. 求解器/步数消融：25→50→100 步，单次 vs 平均 8 次（几乎不用重训，只重新评估）。
2. 加一个"官方风格"软引导消融：双轨迹 + 一致性项，分别调 Λ、β，而不是单个 γ。
3. 补全 SEEN 表；训练选 best epoch 时用调好的 γ。

## 2. DiffCom —— 结论：结构上忠实于官方的 DPS 引导，但似然项与本任务不匹配；可信度：高

**官方做法**：FFHQ 上的无条件扩散先验；测量算子 = DeepJSCC 编码器 + **已知信道、已知噪声**；每步先做一次祖先采样，再减去 ζ·∇‖y − H(x̂₀)‖₂；**从接收信号的解码结果热启动**（按 CSNR 选起始步）；几百到 1000 步。

**本项目**：无条件 DiT 先验（只用干净信号训练）；H = 恒等，似然 ‖y − x̂₀‖₂（逐样本范数，对 x_t 求梯度，减 ζ·grad）；DDIM 25 步；从纯噪声起步；ζ 在验证集的 {10, 30, 100} 上选。

| 项 | 判断 |
|---|---|
| 先验无条件、不偷看干净信号/干扰标签 | 一致 |
| DPS 引导形式（逐样本 L2 范数、对 x_t 求梯度、常数 ζ） | 一致 |
| H = 恒等 | 偏差：官方的 y 与 x 之间是已知算子 + 已知小噪声；我们的 y = x + **未知强干扰** + 噪声，恒等 H 等于假设"y≈x"，把干扰当成了白噪声 |
| 起点 | 偏差：官方热启动，我们从纯噪声开始 |
| 步数/采样器 | 偏差：官方数百到 1000 步 + 祖先采样，我们 25 步 + DDIM(η=0) |
| ζ 调参 | 无测试集泄漏；但只有 3 个网格点，没有 ζ=0 对照 |

**为什么 BER ≈ 不处理（0.2257 对 0.2254）**：这不是"引导没生效"。验证集 ζ 越大结果越接近 y（BER 0.411→0.303→0.259→0.254，ζ=1→3→10→30），按信干比逐档看，DiffCom 与"不处理"几乎逐档相同。原因是：先验只描述干净信号，似然把强干扰当白噪声，两者没有任何信息能区分"干扰"和"信号"，后验最优解就是 y。**所以在"恒等 H + 未知干扰"这个设定下它本来就接近不处理。**

**设计：更合理、仍然公平的适配（尚未实现）**
1. 似然改为"y − x 是干扰+噪声"的有色模型：用训练集拟合的干扰+噪声功率谱/协方差做白化残差 ‖Σ_b^(−1/2)(y − x̂₀)‖²（只用训练集统计，不用测试样本的真实干扰）。
2. 热启动：x_init = √ᾱ_s·y + √(1−ᾱ_s)·ε，起始步 s 按估计的信噪/信干比选（与官方 main_diffcom.py 一致）。
3. 调参网格加入 ζ=0（量化引导带来的真实增益）并加密（如 {3,10,20,30,50,100}）；步数 ≥100，试祖先采样。
4. 论文里把现版本作为"忠实但不适配"的 DiffCom，新版本作为"适配后"的版本，两个都报告，避免被质疑把基线做弱。

## 3. Restormer —— 已实现并通过检查

- 文件：`models/baseline/restormer_baseline.py`；`model_type=restormer`（`exp_train.py`、`evaluate_new.py`、`train.py` 已接入，参数 `--restormer_dim`，默认 48）。
- **忠实保留**：4 级编解码 U 形结构、MDTA（通道维转置自注意力，Q/K 沿序列维 L2 归一化，每头可学习温度）、GDFN（门控深度卷积前馈，扩展因子 2.66）、WithBias LayerNorm、无偏置卷积、skip 拼接后 1×1 降通道（最高分辨率一级不降）、refinement 块、全局残差；默认超参同官方（dim=48，blocks [4,6,6,8]，refinement 4，heads [1,2,4,8]）。
- **1D 改动**：Conv2d→Conv1d；PixelShuffle/Unshuffle 的一维等价写法（2D 版通道 ×4，1D 版 ×2，所以下/上采样的 3 卷积保持通道数不变）；输入输出 = 2（I/Q），真实数据长度 2560→320。
- **训练方式**：不用官方的渐进式训练和 L1 损失，用与本项目 CNN 基线完全相同的损失（MSE + 0.1×频域幅度谱 MSE）、优化器（AdamW lr 3e-4）、EMA、bf16、数据划分，**只比较架构**。
- **验证**：新增 `tests/test_restormer.py`（已加入 `tests/run_all.py`）：形状、梯度、洗牌可逆；并在"高度为 1 的 2D 图像"上与官方 `Attention`/`FeedForward`/`LayerNorm` 逐模块对比，**最大误差 0.0**；一次端到端冒烟（训练 2 个 epoch + 评估）通过。
- **规模/速度**：22.77M 参数（CNN 1.59M）；真实数据长度 2560 时每步约 307 ms（与另外 5 个任务共享 GPU 时的实测；峰值显存 14.6 GB）。10% 设定 12000 步，约 30～60 分钟/个种子。（此前写的“每步 81 ms、16 分钟”是按长度 128 的测试得到的，已更正。）
- **运行计划**：已加入 `exp/fill_plan.py`（23 个任务，名字 `rest_*`）：10% 设定 3 个种子为第一优先级；30%/100%、全量监督、整类留出、K=1/5/10、逐类留出、更难场景、CCIR 为第二优先级。**尚未启动**（补数据任务仍在暂停）。统一总表和 10% 监督表已加入 Restormer 列/行，当前留空。
